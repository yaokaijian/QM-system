使用说明

适用场景

海外代购 / 切货 / 海淘采购后国内二次售卖，需要清晰核算每笔利润。

核心计算逻辑

  • 采购金额：直接填写人民币金额
  • 运费 / 税费 / 合箱费 / 其他费用：全部按人民币填写
  • 总成本 = 采购金额 + 运费 + 税费 + 合箱费 + 其他费用
  • 销售收入 = 国内售价 × 数量
  • 利润 = 销售收入 − 总成本
  • 利润率 = 利润 ÷ 销售收入

推荐使用流程

  • 1. 在「订单管理」新增每笔采购/售卖记录（全部金额按人民币填写）
  • 2. 填写采购金额、运费、税费、合箱费等，系统自动算出利润
  • 3. 多个商品合箱发货：先填相同批次号，再点「合箱运费分摊」自动分配运费/合箱费
  • 4. 状态建议：采购中 → 在途 → 已到货 → 已售出（首页会单独统计已售出利润）
  • 5. 定期到「汇率设置」里备份数据，并开启云端同步

云端同步（Cloudflare）

  • 部署到 Cloudflare Pages 后，设置相同「同步口令」的设备可共享数据
  • 支持手动上传/拉取，也可开启「保存后自动上传」
  • 数据存储在 Cloudflare D1，完全免费额度对个人使用足够

数据安全与自动备份

  • 每次新增/编辑/删除订单会自动保存到本机浏览器，并生成历史版本（最多 8 份）
  • 建议开启「备份提醒」和「保存后自动备份」
  • Chrome/Edge 可点「选择备份文件夹」指定目录
  • 换电脑 / 清缓存前，务必备份一次或同步到云端
